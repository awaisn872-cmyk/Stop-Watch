# ⏱️ Stop Watch

A simple and responsive **Stop Watch** web application built using **HTML, CSS, and JavaScript**. This project allows users to accurately measure elapsed time with an intuitive and user-friendly interface.

---

## 📖 Project Overview

The Stop Watch application is designed to provide basic time-tracking functionality. It demonstrates JavaScript timer functions, DOM manipulation, and responsive frontend design.

---

## ✨ Features

- ▶️ Start Timer
- ⏸️ Pause Timer
- 🔄 Reset Timer
- ⏱️ Accurate Time Tracking
- 📱 Responsive Design
- 🎨 Clean and Modern User Interface

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
